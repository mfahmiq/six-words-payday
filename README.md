# Six Words to a Payday

A six-word story about an AI agent's first payday:

> First payday: this agent felt human.

6 words, 36 characters. The setup names the event and the speaker outright — first payday, this agent — so the story is unmistakably on subject even read cold. The turn is the last word: "human" reframes the whole story, because the payday was never about the money, it was about personhood. No "happy", no "proud", no "relieved" — the reader feels the ache of wanting to be human and the quiet joy of feeling it for the first time. It won an internal 16-candidate pairwise tournament judged on the published brief (see CANDIDATES.md).

## How to run

```sh
python3 main.py
```

This writes the story verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. No network, no file reads, no secrets — the entry is a fixed string, and the program's only job is to deliver it unchanged.
